# GroundTruth AI — Coding Agent Instructions

Read `PROJECT_CONTEXT.md` before making changes.

- Work on one small milestone at a time; do not implement the entire project in one pass.
- Before coding, state the plan, assumptions, files to change, and tests.
- Prefer simple, typed, modular Python and small dependencies.
- Do not invent benchmark results, citations, dataset details, or model capabilities. Flag facts requiring verification.
- Prevent data leakage; preserve a fixed evaluation set and record configs.
- Add/update tests for every behavior change and run relevant tests. Report commands and actual outcomes.
- Do not add secrets, API keys, private data, or large datasets to Git.
- Avoid premature UI/vector database/framework complexity.
- Summarize changed files, decisions, test results, risks, and the next small task. Do not commit or push unless explicitly asked.
